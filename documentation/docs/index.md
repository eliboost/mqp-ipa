# ActiveMQ Artemis @ PostFinance

Welcome to the **PostFinance Message Queuing Platform (MQP)** user guide!

!!! info
    The MQP platform is based on **ActiveMQ Artemis**. All documentation provided here refers specifically to Artemis.
    Other versions of ActiveMQ may differ significantly, and the documentation may not be applicable to them. In the 
    context of our platform, any mention of ActiveMQ specifically refers to ActiveMQ Artemis.
